# Weather icons

Selected static SVG icons from
[Makin-Things/weather-icons](https://github.com/Makin-Things/weather-icons).

The upstream project is licensed under the MIT License. The included
`LICENSE` file contains its copyright and permission notice.

The unsupported SVG blur-filter definitions were removed from the imported
copies for compatibility with Flutter's SVG renderer. Shapes and colors are
otherwise unchanged.
